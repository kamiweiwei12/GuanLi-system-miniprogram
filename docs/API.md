# API 接口文档

> 📌 本文档随接口开发进度同步更新。

---

## 接口规范约定

| 规范项 | 约定 |
|---|---|
| 协议 | HTTPS |
| 请求格式 | JSON (`Content-Type: application/json`) |
| 响应格式 | JSON，统一结构 `Result<T>` |
| 字符编码 | UTF-8 |
| 认证方式 | 微信登录后携带 token（待实现） |
| 版本管理 | URL 路径版本 `/api/v1/` |

---

## 统一响应结构

所有接口返回以下统一结构（待实现）：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | Integer | 业务状态码（200 = 成功） |
| message | String | 提示信息 |
| data | Object / Array / null | 响应数据 |

## 状态码说明

| 状态码 | 说明 |
|---|---|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
