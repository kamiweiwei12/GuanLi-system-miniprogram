## Step 36 — 2026-07-29 — Phase 13: 巡检数据统计分析 + AI 接口

**完成内容**：
- 新增 4 个统计端点（不修改已有 `/statistics`）：
  - `GET /api/v1/statistics/overview` — 总览（总数+正常/故障/隐患+异常率）
  - `GET /api/v1/statistics/area` — 区域排行（按异常率降序）
  - `GET /api/v1/statistics/device` — 设备统计（高频/故障/风险 TOP10）
  - `GET /api/v1/statistics/trend` — 趋势（按日含各 result 类型）
- 新增 4 个 VO：OverviewVO / AreaStatVO / DeviceStatVO / TrendStatVO
- 修改 StatisticsQueryDTO 增加 userId/area/deviceName 字段
- Mapper 新增 3 段 SQL：countByArea / countByDevice / countByDateWithResult
- EMPLOYEE 角色开放统计访问（不再 403）
- Admin 新增 Statistics.vue 统计分析页面（ECharts 多图+Element Plus 表格）
- Admin Sidebar 新增"统计分析"菜单
- 新增 AI 报告接口：`POST /api/v1/ai/report`
- AiPromptBuilder — 将统计数据转为自然语言 Prompt 文本
- 新增 4 个 AI 模块文件：AiReportRequestDTO / AiReportVO / AiReportService / AiReportServiceImpl / AiReportController
- 新增测试数据脚本：database/test-data.sql + database/test-data-clean.sql
- 配置修复：application-dev.yml 改用 inspection 用户、.env 补全 jdbc: 前缀
- 中文乱码修复：docker-compose.yml 增加 MYSQL_CHARSET/MYSQL_COLLATION、database/fix-encoding.sql
- 新增 docs/Phase13-验收指南.md 和 docs/Docker-部署注意事项.md

**技术决策**：
- 所有统计使用 MyBatis SQL GROUP BY 聚合，不循环拉全表
- 权限通过 StatisticsServiceImpl.applyPermissionFilter() 统一处理
- AI 接口不接入真实 AI 服务，仅返回统计摘要 + Prompt
- 保留已有 StatisticsVO 和 Dashboard.vue 不变

**验证结果**：
