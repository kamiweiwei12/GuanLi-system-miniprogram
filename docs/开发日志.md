## Step 19 — 2026-07-24 — 图片显示修复

**完成内容**：
- 修复微信小程序图片无法显示问题
- 根因：小程序 `<image src="/uploads/xxx.jpg">` 以 `/` 开头的路径被解析为本地文件路径，不发起 HTTP 请求
- 方案：后端 `InspectionRecordServiceImpl.toVO()` 中拼接 `fileBaseUrl + imageUrl` 返回完整 HTTP URL
- 数据库只保存相对路径，VO 层生成完整 URL
- 后端 `application.yml` 新增 `file.base-url` 配置

**技术决策**：
- 不在数据库保存完整域名（支持多环境部署）
- 不在前端拼接 URL（避免小程序硬编码域名）
- 使用 `@Value("${file.base-url}")` 注入，支持 Spring profile 和环境变量
