## Step 25.1 — 2026-07-24 — 数据库结构同步修复

**问题**：已有数据库中 `inspection_record` 表缺少 `user_id` 字段和 `idx_record_user_id` 索引。
**根因**：Phase 5 修改了 `init.sql` 中 `CREATE TABLE IF NOT EXISTS` 语句，但该语句对已存在的表不生效。项目无数据库迁移机制（Flyway/Liquibase）。

**修复 SQL**（需手动执行）：
```sql
ALTER TABLE inspection_record
ADD COLUMN user_id BIGINT NOT NULL DEFAULT 0 COMMENT '提交用户 ID（0=历史数据）';

CREATE INDEX idx_record_user_id ON inspection_record (user_id);
```

**验证 SQL**：
```sql
DESC inspection_record;  -- 确认 user_id 列存在
SHOW INDEX FROM inspection_record WHERE Key_name = 'idx_record_user_id';  -- 确认索引存在
```

**注意**：不修改 Java 代码、Mapper、小程序。此修复为环境运维操作，不纳入 Git commit。
