- deleteById 采用软删除（SET is_deleted=1），不物理删除

- 创建 InspectionRecordService 接口（submitReport、getById）
- 创建 InspectionRecordServiceImpl 实现类
  - 参数校验（8 个必填字段 + result 范围 0~2）
  - DTO 转 Entity（不含系统字段）
  - @Transactional(rollbackFor = Exception.class)
  - 构造器注入（InspectionRecordMapper + InspectionImageMapper）
- result 状态值调整：0=正常, 1=故障, 2=隐患

**技术决策**：
- Service 层负责参数校验 —— Controller 可绕过，Service 是最后防线
- 使用 BusinessException 替代 IllegalArgumentException —— 统一业务异常，后续可做全局异常处理
- 构造器注入替代字段 @Autowired —— 更易测试，依赖更明确
- submitReport 返回 Long（记录 ID）而非 Entity —— 减少返回数据量，调用方可再按需查询
