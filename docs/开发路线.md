## 项目架构原则

### 1. 前后端分离

```
miniprogram/    微信小程序端
admin/          Vue3 管理后台
backend/        Spring Boot API（统一后端）
```

### 2. 权限原则

- ✅ 后端控制权限（UserContext.isAdmin / isDeptAdmin）
- ✅ 前端只负责展示和用户体验
- ❌ 禁止仅通过隐藏菜单实现权限

### 3. 数据原则

- ✅ 统计必须后端 SQL GROUP BY + 聚合
- ❌ 禁止前端拉取全部数据后自行计算

### 4. 移植原则

- 不依赖本机绝对路径
- 不提交 node_modules
- 环境变量管理配置
- Docker 可部署
- 新电脑 clone 后可直接运行
