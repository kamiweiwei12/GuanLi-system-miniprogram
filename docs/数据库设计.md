|---|---|
| 数据库类型 | MySQL 8.0+ |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |
| 存储引擎 | InnoDB |

---

## 命名规范

| 对象 | 规范 | 示例 |
|---|---|---|
| 数据库名 | 小写 + 下划线 | `inspection_db` |
| 表名 | 小写 + 下划线，单数形式 | `inspection_record` |
| 字段名 | 小写 + 下划线 | `device_name` |
| 主键 | 统一使用 `id`，自增 BIGINT | `id BIGINT AUTO_INCREMENT` |
| 索引名 | `idx_表名_字段名` | `idx_record_department` |
| 创建时间 | 统一 `created_at` | `created_at DATETIME DEFAULT CURRENT_TIMESTAMP` |
| 更新时间 | 统一 `updated_at` | `updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` |

---

## 表设计原则

| 原则 | 说明 |
|---|---|
| 主键 | 所有表必须有自增主键 `id` |
| 时间戳 | 所有表必须有 `created_at` 和 `updated_at` |
| 软删除 | 业务表使用 `is_deleted` 标记，不物理删除 |
| 字符集 | 统一 `utf8mb4` |
| 索引 | 为高频查询字段建立索引 |
| 外键 | 不使用物理外键，由应用层保证数据一致性 |
| YAGNI | 只设计当前需求明确的字段，不预留未来可能用到的字段 |

## 数据表

### inspection_record（巡检记录表）

#### 业务字段

| 字段名 | 类型 | 约束 | 说明 | 需求来源 |
|---|---|---|---|---|
| department | VARCHAR(100) | NOT NULL | 部门 | 员工填写"部门" |
| employee_name | VARCHAR(50) | NOT NULL | 姓名 | 员工填写"姓名" |
| phone_number | VARCHAR(20) | NOT NULL | 手机号 | 员工填写"手机号" |
| area | VARCHAR(200) | NOT NULL | 巡检区域 | 员工填写"区域" |
| inspection_time | DATETIME | NOT NULL | 巡检时间（业务时间） | 员工填写"日期"；与 created_at 区分以支持补录 |
| device_name | VARCHAR(200) | NOT NULL | 设备名称 | 员工填写"设备名称" |
| result | TINYINT | NOT NULL | 巡检结果状态码 | 员工填写"巡检结果"；固定编码便于统计 |
| description | TEXT | NULLABLE | 详细描述 | 员工填写"详细描述" |

#### 系统字段

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 记录创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 记录更新时间 |
| is_deleted | TINYINT(1) | NOT NULL, DEFAULT 0 | 软删除标记（0=正常, 1=已删除） |

#### result 状态码约定

| 状态码 | 含义 |
|---|---|
| 0 | 正常 |
| 1 | 异常 |

状态码与显示文本的映射由程序常量管理。

### inspection_image（巡检图片表）

#### 业务字段

| 字段名 | 类型 | 约束 | 说明 | 需求来源 |
|---|---|---|---|---|
| record_id | BIGINT | NOT NULL | 关联的巡检记录 ID | 图片绑定到巡检记录 |
| image_url | VARCHAR(500) | NOT NULL | 图片存储路径 | 员工可选上传"图片" |

#### 系统字段

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 记录创建时间 |

> image 表不设 `updated_at` 和 `is_deleted`：图片只追加，修改时替换记录或物理删除。

## 索引设计

| 索引名 | 表 | 字段 | 类型 | 用途 |
|---|---|---|---|---|
| idx_record_department | inspection_record | department | NORMAL | 管理员按部门筛选 |
| idx_record_area | inspection_record | area | NORMAL | 管理员按区域筛选 |
| idx_record_inspection_time | inspection_record | inspection_time | NORMAL | 管理员按日期筛选 |
| idx_record_device | inspection_record | device_name | NORMAL | 管理员按设备筛选 |
| idx_image_record_id | inspection_image | record_id | NORMAL | 按记录查询关联图片 |

|---|---|---|
| 部门 | department | inspection_record |

| 区域 | area | inspection_record |
| 日期 | inspection_time | inspection_record |
