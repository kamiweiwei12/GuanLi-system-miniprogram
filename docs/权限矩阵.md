# API 权限矩阵

> 📌 Phase 14 输出文档：所有 API 端点的角色权限要求。

## 角色定义

| 角色 | role_code | 说明 |
|---|---|---|
| 系统管理员 | ADMIN | 全部数据，用户管理，系统配置 |
| 部门管理员 | DEPT_ADMIN | 本部门数据，Dashboard 可见 |
| 普通员工 | EMPLOYEE | 仅自己的巡检数据，统计可查看自己 |
| 匿名用户 | — | 仅 `/ping` 和 `/login` |

## 数据过滤规则

| 角色 | 查询过滤 |
|---|---|
| ADMIN | 无过滤，返回全部数据 |
| DEPT_ADMIN | 按 `sys_user.department_id` → `inspection_record.department` 过滤 |
| EMPLOYEE | 按 `user_id` 过滤 |
