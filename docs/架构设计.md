#### 图片上传

```
微信小程序 report.ts
  ↓ wx.uploadFile (POST /api/v1/upload/image)
```

## 架构分层

采用四层结构：Controller → Service → Mapper → Database。

| 层级 | 目录 | 职责 | 依赖方向 |
|---|---|---|---|
| Controller | `controller/` | 接收 HTTP 请求、调用 Service、返回响应 | Service 接口 |
| Service | `service/` + `service/impl/` | 业务逻辑、事务管理、VO 转换 | Mapper 接口 |
| Mapper | `mapper/` | 数据库操作（CRUD） | Entity |
| Entity | `entity/` | 数据库表映射 | 无 |

### 数据传输对象

| 对象类型 | 目录 | 用途 |
|---|---|---|
| DTO | `dto/` | 接收前端请求参数 |
| VO | `vo/` | 返回给前端的视图数据 |
| Entity | `entity/` | 数据库表映射 |

### 跨层数据传递约束

- Controller 只接收 DTO，只返回 VO
- Entity 只在 Service 和 Mapper 之间传递，不暴露到 Controller
- Service 接口与实现分离（`service/` 定义接口，`service/impl/` 实现）
- Controller 不直接操作 Mapper

## 用户认证架构（计划 Phase 5-9）

### 认证流程

```
微信小程序
  ↓ wx.login() → code
  ↓
POST /api/v1/login { code }
  ↓
后端: 微信接口 → openid
  ↓
查询 sys_user (WHERE openid = ?)
  ├─ 存在 → 更新登录信息
  └─ 不存在 → INSERT 新用户（默认 role_id = EMPLOYEE）
  ↓
创建 sys_token（UUID, user_id, expire_time = now + 7天）
  ↓
返回 { token, userId, username, role }
  ↓
小程序存储 token 到 storage
  ↓
后续请求 Header: Authorization: Bearer {token}
  ↓
Interceptor → 查询 sys_token → UserContext.set(userId, role)
  ↓
Controller / Service 通过 UserContext 获取当前用户
```

### 权限数据流

```
请求进入
  ↓
Interceptor: 解析 Authorization header
  ↓
TokenService: 查询 sys_token (WHERE token = ? AND expire_time > NOW())
  ├─ 失效 → 401 Unauthorized
  └─ 有效 → UserContext.set(userId, role)
  ↓
Controller: 调用 Service
  ↓
Service: 根据 UserContext.getRole() 过滤数据
  ├─ EMPLOYEE → WHERE user_id = UserContext.getUserId()
  ├─ DEPT_ADMIN → WHERE department_id = UserContext.getDeptId()
  └─ ADMIN → 无过滤（全部数据）
```
